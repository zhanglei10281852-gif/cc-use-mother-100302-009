# 传动设备本地化设计闭环

动力传动设备厂商从来图生产转向面向中国客户自主研发后，同一减速机在矿山、风电、机器人产线会面对不同的环境、载荷与维护要求。本项目提供一组纯 Python 标准库实现的领域契约与应用服务，把**客户现场问题与销售口头承诺**转成**带来源的需求**，经过澄清、冲突分析与优先级确认后形成**产品配置与设计基线**，并关联计算、样机验证、供应商替代与工程变更，支持从客户声音到设计决定的双向追踪。

## 闭环规则

- **带来源的需求**：每条需求必须关联客户声音（现场问题、服务报告、客户来函或销售口头承诺）；口头承诺也必须落到会议纪要等可核验凭证，否则不得登记。
- **澄清与优先级**：需求经澄清后才能确认优先级，只有已确认需求可纳入产品配置与设计基线。
- **冲突门禁**：未解决的安全冲突不得进入发布；安全冲突不能按偏差接受，只能以设计决定解决。
- **受控偏差**：非安全冲突可接受偏差，但必须说明适用客户与有效期限，过期偏差阻断发布。
- **验证覆盖**：基线发布前每条需求必须有通过的计算校核和通过的样机验证；验证失败自动登记冲突并传播。
- **供应商替代**：零件停产传播到所有在用配置；无已批准替代时阻断发布，替代通过工程变更落地。
- **事件传播**：需求撤回、法规更新、零件停产、验证失败传播到受影响配置；已发布基线的配置标记为待重发布，期间不得按旧基线继续交付。
- **交付依据冻结**：已交付序列号保存发布时基线与需求内容指纹；后续需求变化只产生漂移标注，不改写交付依据。
- **双向追踪**：可查询任一配置的有效需求、验证覆盖、开放风险，以及从客户声音 → 需求 → 设计决定/冲突 → 验证 → 基线 → 序列号的完整链路。

## 代码结构

```
src/local_design/
  contracts.py   # 稳定标识、不可变版本、内容摘要（sha256 指纹）
  model.py       # 客户声音、需求、冲突/偏差、配置、决定、计算、
                 # 样机验证、零件/替代、工程变更、基线快照、交付序列号、影响事件
  service.py     # 闭环应用服务：状态流转、发布门禁、事件传播与追踪查询
tests/           # 基础契约测试 + 全流程业务规则测试
run_cli.py       # 命令行全流程冒烟演示
```

## 运行环境

- Python 3.11 或更高版本，无第三方依赖

## 运行测试

```bash
PYTHONPATH=src python -m unittest discover -s tests -v
```

## 编译检查

```bash
python -m compileall -q src tests run_cli.py
```

## 命令行冒烟

```bash
python run_cli.py
```

演示矿山减速机配置从客户声音登记、噪音偏差接受、轴承停产国产化替代、基线发布与序列号交付，到交付后法规更新传播与依据冻结的完整闭环。
